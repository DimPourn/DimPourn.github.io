Personal infrastructure · Hardening and monitoring

My self-hosted security homelab

My homelab runs on a Raspberry Pi 5. Six network layers separate the internet from any service. Containers start with nothing and get only what they need; I review updates. Quiet failures reach my phone as alerts, a path I tested end to end with a synthetic alert. I test the alert rules too: a real zero stays quiet, missing data fires, restored data clears. I write up fixes with their proof and list what the setup doesn't cover.

Personal project · Cyber threat intelligence

Sentinel Linux

Sentinel Linux is a local evidence workspace I built with Codex. It collects public CISA Known Exploited Vulnerabilities records, matches them against my watchlists, adds FIRST EPSS scores to help me prioritize, and produces briefings that cite their sources. It helps me answer one question: which vulnerability deserves a closer look, and which source backs that up? It's built on FastAPI and React and runs in rootless Podman.

  • CISA KEV
  • FIRST EPSS
  • FastAPI
  • React

Training project · Investigation practice

Cyber Case Lab

Cyber Case Lab is a training project: a local investigation workbench where I practice working a case from evidence to report. I select log excerpts, draft a timeline, follow each citation back to its source line, review findings, and export a Markdown case report. A staged fictional incident makes me record a decision before the next piece of evidence is revealed.

Coming soon: Suggestions from the CyberCodex model, each checked against the cited evidence before I accept it.
